# Lancaster Calculator

Computes the semiotic ratio Ψ from symbolic constants χ, C, and S using the Lancaster Compression Layer.

## Equation

Ψ = Λ(χ × C × S²)

Where Λ(z) = ln(z + 1) × e^(−1/z)
